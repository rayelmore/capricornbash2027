# Capricorn Birthday Bash 2027

One-stop site for the Capricorn Bash (Jan 14–19, 2027, Mission Resort + Club): updates, timeline, tee times and pairings, event details, photos.

- Live: https://capricorn.powerflightgolf.com
- Try with sample data: add `?demo=1` to the address
- Data lives in Firebase (triple-g project, `cb_` collections). Guest names and payment details are entered by organizers and are not stored in this repo.
